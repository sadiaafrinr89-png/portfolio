Selected Projects

Knowledge Repository

A searchable, role-aware document hub for BRAC's internal teams. I mapped how people actually searched for files, then designed permission-aware filtering and a lightweight publishing flow so the right document surfaces fast and ownership stays clear.

Inventory Management System

An operations tool that replaces manual spreadsheet counts with a live view of stock. I designed the intake-to-reporting flow end to end, prioritizing the numbers operators need to see first.

We Learn

New onboarding and navigation flows for BRAC's learning platform. I simplified the path from the course catalog to the first lesson, and tested it with real learners before handoff.

Biometric Verification System

A calmer fingerprint-verification flow with clear status at every step. I designed guided instructions and accessible error recovery so a routine security check feels less stressful.

Shohoj Import BD

A guided, sectioned interface for a dense import-management workflow. I broke a one-page form overload into clear steps based on shipment type, showing only the fields each step needs.
